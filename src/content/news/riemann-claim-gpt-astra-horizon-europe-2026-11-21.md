### 2. OpenAI releases GPT-6.2 Astra and GPT-6.2 Sol in the API

*Tools & models* · Simon Willison · 2026-11-17

OpenAI has released GPT-6.2 Astra, a frontier model for hard projects, and GPT-6.2 Sol, an efficient model for everyday work. Both are available in the API as gpt-6.2-astra and gpt-6.2-sol. Astra costs $8 per million input tokens and $40 per million output tokens, which is 80% of the price of GPT-6 Astra.

**Why it matters for researchers:** If your group pays for API access, compare the new prices with your current model before you set a default for analysis or writing pipelines. Sol suits routine tasks, while Astra is aimed at the hardest ones.
